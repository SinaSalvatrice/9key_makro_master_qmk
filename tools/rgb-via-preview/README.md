# RGB VIA Preview Tool

Visualisiert VIA-/QMK-Lighting-Modi.

## Features

- RGBLight / Underglow Vorschau
- RGB Matrix Vorschau
- Backlight Vorschau
- VIA-konforme Kategorien
- React + Vite

## Start

```bash
cd tools/rgb-via-preview
npm install
npm run dev
```

## Ziel

Dieses Tool ist absichtlich vom eigentlichen QMK-Firmwarecode getrennt.

Es dient zum:

- Planen von Animationen
- Testen von Layer-Farben
- Vergleichen von VIA-Modi
- Simulieren von Effekten

ohne jedes Mal Firmware zu flashen.
